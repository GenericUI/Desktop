# `:desktop:macos` — macOS AppKit / Cocoa Native Backend

## Overview
`:desktop:macos` is the native macOS (`macosX64` and `macosArm64`) backend for GenericUI. It uses Kotlin/Native Objective-C / C-Interop with AppKit (`NSApplication`, `NSWindow`, `NSView`, `NSToolbar`, `NSMenu`), CoreGraphics, CoreText, ImageIO, and Security frameworks. It depends on `:common`, `:systemCommon`, `:desktop:common`, and `:desktop:nativeCommon`.

---

## Single-`commonMain` Architecture & `MacosLauncher`

The GenericUI Gradle plugin (`GenericUiGenerateLaunchersTask`) automatically generates the `macosX64Main` and `macosArm64Main` entry point stubs invoking `MacosLauncher`:

```kotlin
// Auto-generated by GenericUiGenerateLaunchersTask
fun main(args: Array<String>) {
    MacosLauncher.launch(
        args = args,
        title = "My App",
        width = 1280,
        height = 800,
        mainFragmentFactory = { MyMainFragment() }
    )
}
```

`MacosLauncher` (`com.nexustools.genericui.macos.MacosLauncher`) initializes `MacosNativeBootstrap`, creates the primary `NSWindow` via `MacosNativeWindowHost`, mounts the root `FragmentHostFragment`, and starts `NSApplication.sharedApplication`. Launching another `@AppFragment` via `AppFragmentLauncher` opens a new `NSWindow` with its own `FragmentHostFragment`.

---

## Window Chrome, `TitleCapabilities`, & Single-Placement `TitleBar`

On `:desktop:macos`, `MacosWindowImpl` reports native desktop `TitleCapabilities` (`isTitleBarRequired = true`, `supportsCustomComponents = true`, `canEmbedComponentsInTitleBar = true`, `titleBarRendersAsNavbar = false`):
- **Custom TitleBar Components**: Leading, center, and trailing components added to `TitleBar` are embedded into the `NSWindow` titlebar (`NSToolbar` / `NSWindowTitleHidden` accessory area) and marked with `mountedInTitleBar = true`. `MacosNativeWindowHost` excludes `mountedInTitleBar` components from the window content `NSView` so each titlebar widget is rendered strictly once.
- **Native macOS MenuBar**: `MenuBar` attaches to `NSApplication.mainMenu` (the system-wide macOS menu bar at the top of the screen) while remaining synchronized with the active `MacosWindowImpl`.

---

## Apple `.app` Bundle Resources (`MacosResourceResolverImpl`)

During the Gradle build, `GenericUiCompileResourcesTask` packages `src/commonMain/resources/` into `.app/Contents/Resources/` (including localized `.lproj/Localizable.strings` and raw/drawable/font assets).

At runtime, `MacosResourceResolverImpl` (`com.nexustools.genericui.macos.system.MacosResourceResolverImpl`) resolves resources via `NSBundle.mainBundle` (`pathForResource:ofType:inDirectory:` and `localizedStringForKey:value:table:`), returning `file://` URLs and raw byte streams.

---

## Key Package Structure (`com.nexustools.genericui.macos`)

- **`MacosLauncher.kt` / `MacosNativeBootstrap.kt` / `MacosNativeWindowHost.kt`**: AppKit bootstrap, `NSApplicationDelegate`, `NSWindow` creation, and event loop.
- **`widget/*` & `container/*`**: Native AppKit `NSControl` / `NSView` widget and container implementations (`NSButton`, `NSTextField`, `NSTextView`, `NSSlider`, `NSComboBox`, `NSDatePicker`, `NSColorWell`, `NSSplitView`, `NSTabView`, `NSScrollView`).
- **`system/*`**: `MacosResourceResolverImpl` (`NSBundle`), `MacosPreferenceStoreImpl` (`NSUserDefaults`), `MacosKeystoreImpl` (macOS Keychain Services `SecItemAdd` / `SecItemCopyMatching`), `MacosClipboardImpl` (`NSPasteboard`), `MacosFileBrowserDialogImpl` (`NSOpenPanel` / `NSSavePanel`), and `MacosThemeDetectorImpl` (`NSAppearance`).
