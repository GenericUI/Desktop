# `:desktop:macos` — macOS AppKit / Cocoa Native Backend

## Overview
`:desktop:macos` is the native macOS (`macosX64` and `macosArm64`) backend for GenericUI. It uses Kotlin/Native Objective-C / C-Interop with AppKit (`NSApplication`, `NSWindow`, `NSView`, `NSCursor`, `NSToolbar`, `NSMenu`), CoreGraphics, CoreText, ImageIO, and Security frameworks. It depends on `:common`, `:systemCommon`, `:desktop:common`, and `:desktop:nativeCommon`.

---

## Single-`commonMain` Architecture & `MacosLauncher`

The GenericUI Gradle plugin (`GenericUiGenerateLaunchersTask`) automatically generates the `macosX64Main` and `macosArm64Main` launcher stubs invoking `MacosLauncher`:

```kotlin
// Auto-generated by GenericUiGenerateLaunchersTask
fun main(args: Array<String>) {
    MacosLauncher.launch(
        args = args,
        title = "My App",
        width = 1280,
        height = 800,
        mainFragmentFactory = { MyMainFragment() }
    )
}
```

When `styles { globalStyleSheet = "styles/main.scss" }` is configured in `build.gradle.kts`, the generated startup code automatically attaches the precompiled `PrecompiledStyleSheet` via `app.addStyleSheet(...)`.

## Native AppKit Control Rendering (`BootstrapType.NONE` Default) & Semantic `BootstrapType` Tinting

1. **`BootstrapType.NONE` Default & Zero Bootstrap CSS Styling**:
   - Native macOS applications **never** use Bootstrap CSS styling.
   - When `component.getBootstrap().type == BootstrapType.NONE` (the default) and no inline `ComponentStyle` background/border is set, `:desktop:macos` renders the **authentic AppKit system control** (`NSButton`, `NSTextField`, `NSSlider`, `NSSwitch`, `NSPopUpButton`) styled by macOS Aqua / Dark Aqua (`NSApp.effectiveAppearance`).
2. **Semantic `BootstrapType` Tinting**:
   - When a semantic `BootstrapType` (`DANGER`, `PRIMARY`, `SUCCESS`, `WARNING`, `INFO`, `SECONDARY`, `LIGHT`, `DARK`, `LINK`) is set on `component.getBootstrap().type`, `:desktop:macos` emulates `BootstrapType` by **tinting the native AppKit control** (`bezelColor` / `contentTintColor` / layer fill via `DesktopBaseNativeImpl.resolveSemanticBootstrapColor(darkTheme)`), supporting `outline = true/false`.
   - `component.getStyle().setAccentColor(color)` (`accent-color`) sets the control's active accent fill color.
   - Unsupported CSS properties and CSS transitions are **silently ignored** on native AppKit controls.
3. **Strict User CSS Class Isolation**:
   - `addClass`, `removeClass`, `hasClass`, `getClasses()`, and `getClass()` return **only** user-added custom classes (`styleSnapshot.customClasses`).

## Custom Cursor Synthesis (`MacosCursorTranslator`)

`MacosCursorTranslator` (`com.nexustools.genericui.macos.MacosCursorTranslator`) translates any `CssCustomCursor` (PNG `ResourceID`, SVG `ResourceID`/markup, or `ImageBuffer` with `hotspotX` and `hotspotY`) into a macOS AppKit `NSCursor`:
- Resolves the PNG, rasterized SVG, or `ImageBuffer` via `cursor.resolveToImageBuffer()` and encodes cached PNG bytes (`MacosCursorTranslator.encodeToNsImagePngBytes(cursor)`).
- Constructs a Retina-aware `@1x`/`@2x` `NSImage` (`[NSImage initWithData:]`) and `[NSCursor initWithImage:nsImage hotSpot:NSMakePoint(hotspotX, hotspotY)]` applied to the `MacosViewHandle` via `MacosCursorTranslator.applyToViewHandle` during AppKit `resetCursorRects` / `cursorUpdate:`.

## `IApplication` Theming (`ThemeMode.AUTO`, `DARK`, `LIGHT`)

`IApplication` defaults to **`ThemeMode.AUTO`** (`setTheme`, `getTheme`, `getResolvedTheme`):
- Detects the active macOS appearance via `NSApp.effectiveAppearance` (`NSAppearanceNameDarkAqua` vs. `NSAppearanceNameAqua`) and listens for live system appearance changes.
- Calling `app.setTheme(ThemeMode.DARK)` or `app.setTheme(ThemeMode.LIGHT)` sets `NSApp.appearance` (`NSAppearanceNamed(NSAppearanceNameDarkAqua)` / `NSAppearanceNameAqua`), while `ThemeMode.AUTO` resets `NSApp.appearance = nil` so the app tracks macOS System Settings automatically.

## Window Chrome, `TitleCapabilities`, & Single-Placement `TitleBar`

On `:desktop:macos`, `MacosWindowImpl` reports native desktop `TitleCapabilities` (`isTitleBarRequired = true`, `supportsCustomComponents = true`, `canEmbedComponentsInTitleBar = true`, `titleBarRendersAsNavbar = false`):
- **Single-Placement `TitleBar`**: Custom leading, center, and trailing components added to `TitleBar` are embedded into the `NSWindow` titlebar (`NSToolbar` / accessory area) and marked `mountedInTitleBar = true` so `MacosNativeWindowHost` excludes them from the window content `NSView`.
- **Native macOS MenuBar**: `MenuBar` attaches to `NSApplication.mainMenu` at the top of the screen.

## Apple `.app` Bundle Resources (`MacosResourceResolverImpl`)

During the Gradle build, `GenericUiCompileResourcesTask` packages `src/commonMain/resources/` into `.app/Contents/Resources/`. At runtime, `MacosResourceResolverImpl` resolves resources via `NSBundle.mainBundle`.
