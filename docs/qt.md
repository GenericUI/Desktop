# `:desktop:qt` — Linux Qt Native Backend (`linuxX64`)

## Overview
`:desktop:qt` is the native Linux Qt (`linuxX64`) backend for GenericUI. It uses Kotlin/Native C-Interop (`qt.def`) with a C ABI wrapper over `QApplication`, `QMainWindow`, `QWidget`, `QPainter`, `QMenuBar`, `QStatusBar`, and `QResource`, and depends on `:common`, `:systemCommon`, `:desktop:common`, `:desktop:nativeCommon`, and `:desktop:linuxCommon`.

---

## Single-`commonMain` Architecture & `QtLauncher`

The GenericUI Gradle plugin (`GenericUiGenerateLaunchersTask`) generates the `linuxX64Main` entry point stub invoking `QtLauncher`:

```kotlin
// Auto-generated by GenericUiGenerateLaunchersTask
fun main(args: Array<String>) {
    QtLauncher.launch(
        args = args,
        title = "My App",
        width = 1280,
        height = 800,
        mainFragmentFactory = { MyMainFragment() }
    )
}
```

`QtLauncher` (`com.nexustools.genericui.qt.QtLauncher`) runs `QtNativeBootstrap.ensureInstalled()`, initializes `QApplication` via `QtNativeWindowHost`, mounts the root `FragmentHostFragment`, and starts `QApplication::exec()`. Launching another `@AppFragment` via `AppFragmentLauncher` opens a new `QMainWindow`.

---

## Window Chrome, `TitleCapabilities`, & Single-Placement `TitleBar`

`QtWindowImpl` reports native desktop `TitleCapabilities` (`isTitleBarRequired = true`, `supportsCustomComponents = true`, `canEmbedComponentsInTitleBar = true`, `titleBarRendersAsNavbar = false`):
- **Single-Placement `TitleBar`**: Custom leading, center, and trailing components attached to `TitleBar` are mounted in the `QMainWindow` custom titlebar widget and flagged with `mountedInTitleBar = true` so `QtNativeWindowHost` excludes them from the central body widget.
- **`QMenuBar` & `QStatusBar`**: Mapped directly to `QMainWindow::menuBar()` and `QMainWindow::statusBar()`.

---

## Compiled `QResource` Bundle (`QtResourceResolverImpl`)

During the Gradle build, `GenericUiCompileResourcesTask` generates `genericui_resources.qrc` from `src/commonMain/resources/` and compiles it via Qt's `rcc` tool into a binary `.rcc` resource bundle.

At runtime, `QtResourceResolverImpl` (`com.nexustools.genericui.qt.system.QtResourceResolverImpl`) registers the `.rcc` bundle (`QResource::registerResource`) and resolves `:/genericui/...` paths, strings, colors, dimensions, fonts, and raw byte streams.

---

## Key Package Structure (`com.nexustools.genericui.qt`)

- **`QtLauncher.kt` / `QtNativeBootstrap.kt` / `QtNativeWindowHost.kt`**: `QApplication` initialization, `QMainWindow` host, and Qt event loop dispatch (`QTimer::singleShot`).
- **`widget/*` & `container/*`**: Native `QWidget` implementations (`QPushButton`, `QLabel`, `QLineEdit`, `QTextEdit`, `QComboBox`, `QSlider`, `QProgressBar`, `QSplitter`, `QTabWidget`, `QScrollArea`).
- **`system/*`**: `QtResourceResolverImpl` (`QResource`), `QtClipboardImpl` (`QClipboard`), `QtFileBrowserDialogImpl` (`QFileDialog`), and XDG storage classes from `:desktop:linuxCommon` (`LinuxXdgConfigDirectoryImpl`, `LinuxXdgCacheDirectoryImpl`, `LinuxXdgPreferenceStoreImpl`).
